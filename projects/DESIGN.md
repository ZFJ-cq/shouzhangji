# DESIGN.md

## 气质与意象

周日下午的书桌，一本奶油色 Moleskine 手账本摊开在浅木色桌面上，旁边放着一小盆薄荷、一杯抹茶拿铁。页面用柔和的灰色墨水书写，关键数字用薄荷绿和腮红粉荧光笔标注，页边装饰着叶子和小星星的手绘涂鸦。整体氛围：温暖、治愈、有序、私密。

## 配色方案

| 用途 | 色值 | 意象 |
|------|------|------|
| 页面底色 | `#FFFDF7` | 手账本纸张的奶白色 |
| 卡片/区块底色 | `#FFF8F0` | 微微泛黄的奶油色 |
| 主色-薄荷绿 | `#7BC8A4` | 薄荷叶的清新绿 |
| 主色-浅薄荷 | `#A8D8B9` | 薄荷叶的浅色面 |
| 收入色 | `#6BBF9E` | 柔和的草木绿 |
| 支出色 | `#E8A0A0` | 干玫瑰花瓣的柔粉 |
| 强调色-暖杏 | `#F2C6A0` | 午后暖阳的杏色 |
| 文字主色 | `#5A5A5A` | 铅笔灰 |
| 文字次色 | `#9B9B9B` | 浅灰墨 |
| 边框/分隔 | `#E8E0D4` | 纸张折痕的淡棕 |

## 字体排版

- 标题字体：`"ZCOOL XiaoWei"` (Google Fonts) — 带手写感的中文衬线体
- 正文字体：系统默认无衬线
- 数字展示：等宽数字，加粗，使用薄荷绿或柔粉着色
- 排版节奏：宽松留白，行高 1.8，段间距大于段内间距

## 视觉策略

- 卡片使用 1px 淡棕边框 + 微弱阴影，模拟纸张浮起感
- 圆角统一 12px-16px，不使用尖锐直角
- 装饰元素：手绘风虚线分隔、小叶子/星星 SVG 点缀
- 按钮使用圆角药丸形，hover 时轻微上浮
- 收入/支出用柔和色彩区分，避免刺眼的红绿色

## 动效与交互

- 页面切换：淡入 200ms ease-out
- 卡片 hover：translateY(-2px) + 阴影加深
- 数字变化：轻微弹跳动画
- 按钮点击：scale(0.97) 微缩反馈
- 整体节奏：轻柔、舒缓，不追求速度感

## 设计禁忌

- 不使用纯黑 `#000`，文字一律用暖灰
- 不使用高饱和度色彩（正红、正蓝、正绿）
- 不使用直角边框或尖锐三角形
- 不使用渐变背景（保持纸张质感）
- 不使用过于科技感的元素（金属光泽、霓虹、玻璃态）
- 不使用大面积深色区块
